# Next games

Ideas that were weighed for a game and not built yet. Pick one, plan it (docs/review.md: a new game gets its plan reviewed first), and take it off this list in the pull request that adds it. Describe each in plain words: never name another game.

| Idea | What it is | Notchup twist | Notes |
|---|---|---|---|
| **Window Watch** | A memory game: an office block at night lights its windows in a pattern, one note each, and you repeat it. The pattern grows by one each round; a mistake ends the run. | The logo is the building's sign and notches up every round. | Small (about 2 sessions). Windows must glow on and off slowly, never flash; screen readers need the pattern another way, for example as notes and spoken window names. |
| **Courier Run** | A lane-crossing game: hop the Notchup courier across a night street of slow trams and bikes, then over moving rooftop gaps, to drop off a parcel. Each delivery makes the next street a little busier. | The parcels are the logo's parts; a run puts the mark back together. | Bigger (about 4 sessions). Traffic is always moving, so keep it calm; check the demo budget early. |
